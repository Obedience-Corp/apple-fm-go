First experimental beta of the Go wrapper for Apple's `fm` CLI.

## Included

- Context-aware calls for text responses, image prompts, structured output, availability, and token counts.
- Subprocess cancellation, Unix process-group cleanup, and errors preserving stdout/stderr.
- Runnable examples, isolated fake-process tests, native smoke-test commands, and compatibility documentation.

## Install

```sh
go get github.com/Obedience-Corp/apple-fm-go@v0.1.0-beta.1
```

Requires Go 1.24+. Inference targets macOS 27 with Apple's `fm` executable and an eligible Apple Intelligence installation. The Go module compiles on Linux, macOS, and Windows on amd64 and arm64 without CGo.

## Validation and limitations

The release is based on merged main commit `5f050164135e0a8f9813802d6a7cea1d021b75c2`. Fake-process tests passed with the race detector in Docker; formatting, vet (including the native-test build tag), golangci-lint, module verification, and all six cross-builds passed.

**Live macOS 27 `fm` compatibility has not been verified.** Command spellings, output formats, and error categories remain provisional. This beta is for API evaluation; do not treat it as native compatibility certification. Streaming, persistent sessions, and tool calling are not exposed. See [the compatibility review](https://github.com/Obedience-Corp/apple-fm-go/blob/v0.1.0-beta.1/docs/compatibility.md).

This first beta was validated and published manually from already-merged main. Automated publication for subsequent beta tags is introduced separately; it was not used to validate this tag.

## [0.1.0-beta.1]

First experimental source release, based on merged main commit `5f050164135e0a8f9813802d6a7cea1d021b75c2`.

- Context-aware subprocess client for `Respond`, `Available`, `CountTokens`, and `SchemaObject`.
- Prompt instructions, model selection, image paths, and structured JSON output.
- Wrapped errors preserving process output and cancellation; Unix process-group cleanup.
- Fake-process regression tests, native smoke checks, and six-platform compilation.
- README examples and a dated Apple Foundation Models compatibility review.

Native macOS 27 `fm` compatibility remains unverified. CLI flags and error categories are provisional; this beta is not a stable compatibility guarantee.
